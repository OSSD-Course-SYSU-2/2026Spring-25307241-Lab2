## 🔧 问题排查

### 如果还是无法滚动

1. **检查布局**
```typescript
// 确认Scroll组件使用layoutWeight
Scroll() {
  // ...
}
.layoutWeight(1) // ✅ 正确
// .height('100%') // ❌ 错误
```

2. **检查内容高度**
- 确保内容高度 > 屏幕高度
- 手表端屏幕高度约 300-400px
- 内容应该超过这个高度

3. **检查父容器**
```typescript
// 确认父容器使用layoutWeight
Column() {
  // 内容区域
  Column() {
    buildTrainingGround()
  }
  .layoutWeight(1) // ✅ 正确
  
  // 底部导航栏
  buildBottomNav()
}
```

### 如果图标不显示

1. **检查字体**
- 确认使用系统支持的emoji
- 避免使用自定义图标字体

2. **检查布局**
- 确认没有裁剪（clip）
- 确认没有溢出隐藏（overflow: hidden）

3. **检查颜色**
- 确认字体颜色与背景对比度足够
- 白色背景用深色字体
- 深色背景用浅色字体

### 如果滚动卡顿

1. **检查内容**
- 减少不必要的组件
- 避免复杂动画

2. **检查性能**
- 使用性能分析工具
- 检查内存占用

## 🎯 重点检查项

### 最容易出问题的地方

1. **Scroll组件的高度设置**
   - ❌ 不要使用 `.height('100%')`
   - ✅ 应该使用 `.layoutWeight(1)`

2. **内容是否足够**
   - ❌ 内容太少，没有滚动需求
   - ✅ 添加足够的内容，确保可以滚动

3. **父容器布局**
   - ❌ 父容器没有限制高度
   - ✅ 父容器使用 layoutWeight 或固定高度

4. **图标显示**
   - ❌ 使用不支持的图标字体
   - ✅ 使用系统emoji或标准图标

## 💡 提示

- 如果某个页面无法滚动，重点检查该页面的Scroll组件配置
- 如果图标不显示，尝试更换为其他emoji
- 如果布局混乱，检查padding和margin设置
- 如果性能不好，减少不必要的组件和动画
