# 自由流转功能使用指南

## 概述

本项目已实现HarmonyOS自由流转功能，支持在手表、手机、平板和PC端无缝切换使用。用户可以在不同设备间流转应用状态，实现"一次开发，多端部署"。

## 功能特性

### 1. 多设备支持
- **手表端**：简化UI，保留核心功能，优化触摸体验
- **手机端**：标准布局，完整功能
- **平板端**：大屏优化，支持双栏布局
- **PC端**：桌面级体验，支持键盘鼠标操作

### 2. 流转能力
- **状态保存**：自动保存当前页面状态、训练数据、计算结果
- **状态恢复**：在目标设备上无缝恢复应用状态
- **数据同步**：支持跨设备数据同步

### 3. 自适应UI
- 响应式布局系统
- 自适应字体大小
- 自适应间距和尺寸
- 设备特定功能优化

## 技术实现

### 1. 配置文件

#### module.json5
已配置多设备支持：
```json
{
  "deviceTypes": [
    "phone",
    "tablet",
    "2in1",
    "wearable"
  ],
  "continuable": true
}
```

#### 权限配置
已添加分布式数据同步权限：
```json
{
  "requestPermissions": [
    {
      "name": "ohos.permission.DISTRIBUTED_DATASYNC",
      "reason": "$string:distributed_datasync_reason",
      "usedScene": {
        "abilities": ["EntryAbility"],
        "when": "inuse"
      }
    }
  ]
}
```

### 2. 核心服务

#### DistributedDataManager
分布式数据管理服务，提供：
- 跨设备数据同步
- 数据变化监听
- 流转数据管理

```typescript
// 初始化
const distributedManager = DistributedDataManager.getInstance();
await distributedManager.initialize(context);

// 保存数据
await distributedManager.saveData('key', 'value');

// 同步数据
await distributedManager.syncData();
```

#### ContinueManager
流转管理服务，提供：
- 流转状态管理
- 页面状态保存/恢复
- 设备类型识别

```typescript
// 保存页面状态
ContinueManager.getInstance().saveCurrentPageState('pages/ScoringSimulatorPage');

// 恢复页面状态
const state = ContinueManager.getInstance().restorePageState();
```

### 3. 设备适配工具

#### DeviceUtils
设备类型判断和适配：
```typescript
// 判断设备类型
if (DeviceUtils.isWearable()) {
  // 手表端特殊处理
} else if (DeviceUtils.isPhone()) {
  // 手机端处理
} else if (DeviceUtils.isTablet()) {
  // 平板端处理
}

// 获取适配参数
const spacing = DeviceUtils.getSpacing();
const buttonHeight = DeviceUtils.getButtonHeight();
const fontScale = DeviceUtils.getFontScale();
```

#### ResponsiveLayout
响应式布局系统：
```typescript
// 初始化
ResponsiveLayout.getInstance().initialize(context);

// 获取适配尺寸
const fontSize = ResponsiveLayout.getInstance().getFontSize(16);
const spacing = ResponsiveLayout.getInstance().getSpacing(16);
const size = ResponsiveLayout.getInstance().getSize(100);
```

### 4. 流转生命周期

#### EntryAbility
已实现完整的流转生命周期回调：

```typescript
// 保存迁移数据
onContinue(wantParam: Record<string, Object>): AbilityConstant.OnContinueResult {
  wantParam['currentPage'] = currentPage;
  wantParam['iceTraceData'] = iceTraceData;
  return AbilityConstant.OnContinueResult.AGREE;
}

// 恢复迁移数据
restoreContinueData(want: Want) {
  const currentPage = want.parameters['currentPage'];
  AppStorage.setOrCreate('continuePage', currentPage);
}

// 窗口恢复
onWindowStageRestore(windowStage: window.WindowStage) {
  const continuePage = AppStorage.get<string>('continuePage');
  windowStage.loadContent(continuePage);
}
```

## 使用方法

### 1. 开发者使用

#### 在页面中使用设备适配
```typescript
import { DeviceUtils } from '../common/utils/DeviceUtils';

@Component
struct MyPage {
  build() {
    Column() {
      Text('标题')
        .fontSize(DeviceUtils.isWearable() ? 16 : 24)
        .padding(DeviceUtils.isWearable() ? 8 : 16)
    }
  }
}
```

#### 保存流转状态
```typescript
import { ContinueManager } from '../components/ContinueComponents';

// 在页面aboutToDisappear中保存状态
aboutToDisappear() {
  ContinueManager.getInstance().saveCurrentPageState(
    'pages/MyPage',
    { myData: this.myData }
  );
}
```

### 2. 用户操作

#### 触发流转
1. 在源设备上打开应用
2. 从屏幕右上角下滑打开控制中心
3. 点击"流转"图标
4. 选择目标设备
5. 应用自动在目标设备上恢复

#### 手表端特殊操作
- 手表端简化了部分功能
- 导航栏只显示3个主要Tab
- 部分复杂功能隐藏或简化
- 触摸目标更大，更易操作

## 注意事项

### 1. 开发注意事项

#### 状态管理
- 所有需要流转的状态必须保存到AppStorage
- 使用@StorageLink或@StorageProp装饰器
- 避免使用组件内部状态

#### UI适配
- 使用DeviceUtils判断设备类型
- 使用ResponsiveLayout获取适配尺寸
- 避免硬编码尺寸值

#### 数据同步
- 及时调用syncData同步数据
- 处理数据冲突情况
- 注意数据一致性

### 2. 用户体验

#### 流转提示
- 显示流转状态指示器
- 提供流转成功/失败反馈
- 引导用户完成流转操作

#### 错误处理
- 流转失败时提供重试选项
- 数据丢失时提供恢复选项
- 网络异常时提供友好提示

## 问题排查

### 1. 流转失败
- 检查设备是否在同一网络
- 检查权限是否正确配置
- 检查流转数据是否过大

### 2. 数据不同步
- 检查分布式数据管理器是否初始化
- 检查数据是否正确保存
- 检查网络连接是否正常

### 3. UI显示异常
- 检查设备类型判断是否正确
- 检查适配参数是否合理
- 检查布局是否响应式
