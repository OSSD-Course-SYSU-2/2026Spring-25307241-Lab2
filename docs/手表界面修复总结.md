# 手表界面显示问题修复总结

## 问题描述
手表界面显示不全，无法往下滑，看不到应用图标。

## 问题原因
1. **缺少滚动容器**：buildTrainingGround、buildIceNews、buildProfile等方法使用了`.height('100%')`但没有Scroll组件包裹，导致内容无法滚动
2. **底部导航栏过高**：手表端底部导航栏高度为50，占用了过多屏幕空间
3. **字体和尺寸不适配**：部分字体大小、按钮尺寸没有针对手表端进行优化

## 修复方案

### 1. 添加滚动容器

#### buildTrainingGround
```typescript
// 修复前
Column() {
  // 内容...
}
.width('100%')
.height('100%')
.padding(DeviceUtils.isWearable() ? 10 : 20)

// 修复后
Scroll() {
  Column() {
    // 内容...
    
    // 手表端添加底部间距，确保可以滚动
    if (DeviceUtils.isWearable()) {
      Blank().height(20)
    }
  }
  .width('100%')
  .padding(DeviceUtils.isWearable() ? 8 : 20)
}
.width('100%')
.height('100%')
.scrollBar(BarState.Off)
.edgeEffect(EdgeEffect.Spring)
```

#### buildIceNews
```typescript
// 添加Scroll组件包裹，并优化手表端字体和间距
Scroll() {
  Column() {
    Text('📰 冰闻')
      .fontSize(DeviceUtils.isWearable() ? 18 : 24)
      // ...
    
    // 手表端添加底部间距
    if (DeviceUtils.isWearable()) {
      Blank().height(20)
    }
  }
  .width('100%')
  .padding(DeviceUtils.isWearable() ? 10 : 20)
}
.width('100%')
.height('100%')
.scrollBar(BarState.Off)
.edgeEffect(EdgeEffect.Spring)
```

#### buildProfile
```typescript
// 添加Scroll组件包裹，手表端简化功能入口
Scroll() {
  Column() {
    // 用户信息卡片
    
    // 功能入口 - 手表端简化显示
    if (!DeviceUtils.isWearable()) {
      // 显示完整功能列表
    } else {
      // 手表端只显示计分模拟器按钮
      Button('🧮 计分模拟器')
        .fontSize(14)
        .height(40)
        // ...
    }
    
    // 手表端添加底部间距
    if (DeviceUtils.isWearable()) {
      Blank().height(20)
    }
  }
}
.scrollBar(BarState.Off)
.edgeEffect(EdgeEffect.Spring)
```

### 2. 优化底部导航栏

```typescript
// 修复前
Column() {
  Text('⛸️')
    .fontSize(20)
  Text('训练')
    .fontSize(10)
}
.height(50) // 过高

// 修复后
Column() {
  Text('⛸️')
    .fontSize(18) // 减小字体
  Text('训练')
    .fontSize(9) // 减小字体
}
.height(40) // 减小高度
```

### 3. 优化手表端UI尺寸

#### 字体大小
- 标题：24 → 16-18
- 正文：16-20 → 12-14
- 小字：12-14 → 9-11

#### 按钮尺寸
- 高度：40-50 → 28-40
- 宽度：根据内容自适应
- 圆角：相应减小

#### 间距
- padding：10-20 → 8-10
- margin：相应减小

#### 图标尺寸
- 大图标：60 → 32-40
- 小图标：24 → 18-20

### 4. 手表端功能简化

#### buildProfile
- 隐藏"打分解读"功能入口
- 只保留"计分模拟器"快捷入口

#### buildTrainingGround
- 隐藏"计划"和"记录"按钮
- 只保留"计算器"快捷按钮
- 减小开始训练按钮尺寸
