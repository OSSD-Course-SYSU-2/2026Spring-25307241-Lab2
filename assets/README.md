## 📝 使用说明

1. 运行应用，截取需要的界面截图
2. 将截图保存到本目录，文件名与上述清单一致
3. 使用Git提交并推送到GitHub：
   ```bash
   git add assets/
   git commit -m "Add screenshots"
   git push origin main
   ```
